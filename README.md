# Screen Translator

Оффлайн-переводчик для Windows (русский ↔ английский): обычный переводчик текста и перевод любой области экрана по горячей клавише. Работает без интернета.

*Offline RU↔EN translator for Windows: a text translator plus on-screen OCR translation via a global hotkey.*

## Возможности

- **Текст:** пишете — получаете перевод (язык определяется автоматически).
- **Экран:** `Alt+Q` → выделите область → текст распознаётся и переводится.
- **Варианты перевода и примеры использования** для слов и коротких фраз (оффлайн).
- **Словарь:** сохраняйте переводы, закрепляйте и удаляйте.
- 5 тем оформления, значок в трее, смена горячей клавиши.

## Для пользователей: установка из архива

1. Распакуйте `ScreenTranslator.zip` в папку с коротким латинским путём, например `C:\ScreenTranslator`.
2. Один раз запустите `install.bat`: он установит Python и библиотеки из архива в эту же папку (интернет не нужен, несколько минут). Ничего не устанавливается в систему.
3. Дальше запускайте `Translator.exe`.

Языковые модели и словарь лежат внутри архива, при работе интернет не нужен. Сохранённые слова хранятся в папке `data`. Чтобы удалить программу, удалите папку.

## Для разработчика: структура репозитория

```
src/        исходный код (main.py, lookup.py, paths.py)
tools/      служебные скрипты: модели, словарные данные, сборка архива
assets/     иконка
install.bat       установка для пользователей (Python + библиотеки + Translator.exe)
make_release.bat  собрать zip для раздачи
run.bat           запуск из исходников
setup_dev.bat     создать .venv для разработки
```

Папки `data/`, `models/`, `tesseract/`, `python/`, `build/`, `dist/` создаются локально и **не попадают в git**.

### Запуск из исходников

```
setup_dev.bat              :: один раз
tools\install_models.bat   :: скачать языковые модели Argos (один раз)
run.bat
```

Для перевода экрана нужен [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki) с языками English и Russian (или положите его в папку `tesseract\` рядом с программой, или задайте переменную `TESSERACT_PATH`).

### Варианты перевода и примеры (необязательно)

```
tools\build_lookup.bat
```

Скрипт скачивает словари WikDict и предложения Tatoeba и собирает `data\lookup.db`. Если сервер недоступен, скачайте файлы вручную в браузере и положите в папку проекта или в «Загрузки» — скрипт найдёт их сам. Проверить результат: `python tools\check_lookup.py`.

### Где что лежит

| Что | Где |
|---|---|
| Сохранённые слова, `lookup.db`, логи | `<папка программы>\data` (если её нет — `%APPDATA%\ScreenTranslator`) |
| Модели Argos | переменная `SCREEN_TRANSLATOR_MODELS`, `<папка программы>\models`, `C:\ArgosModels` |
| Tesseract | `TESSERACT_PATH`, `<папка программы>\tesseract`, стандартная папка установки |
